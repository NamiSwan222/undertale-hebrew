# Voice guide: second pass (binding; it overrides glossary.md where they differ)

The user played the first Hebrew version and said: **every character needs its own personality in Hebrew;
the text needs to be more accurate; and drop the biblical or high-register words most people don't know.**
The target reader is a regular Israeli teen or young adult. They know Undertale and play in Hebrew because it's fun.
If a line sounds like a school textbook, a Bible verse or a Google Translate result, rewrite it.

## 1. Register: everyday spoken Hebrew

Write how people in Israel actually talk today. Dialogue is spoken language. Narration (`*` flavour text) is
light, clear storybook Hebrew. It can be playful, but it is never poetic or literary.

**Banned or avoid** (use the right-hand column). Only a sign, notice or official text may keep a formal word, and
only if it is still common today (e.g. "נא לא לגעת" on a sign is fine).

| Don't | Use |
|---|---|
| אנוכי, הנני, הנך, הינו/הינה/הינך | אני, אתה, הוא/היא, זה |
| עתה, כעת | עכשיו |
| אך, אולם, ברם, ואולם | אבל |
| אכן | באמת, נכון, כן |
| הלא, הלוא | נכון ש..., הרי |
| כה (= so) | כל כך |
| שמא, פן | אולי, שלא |
| כיצד | איך |
| מדוע | למה |
| לשווא | סתם, לחינם |
| הבה | בוא, בואו, יאללה |
| נא (in speech) | בבקשה, or just the imperative |
| שכן, מאחר ש, הואיל ו | כי |
| אשר | ש... |
| טרם | עוד לא |
| ובכן | טוב, נו, אז |
| אינני, אינך, איננו (in speech) | אני לא, אתה לא, הוא לא |
| לפיכך, על כן | אז, בגלל זה |
| זוהי, זהו (outside fixed phrases) | זאת, זה |
| יחדיו | ביחד |
| עודני, עודך | אני עדיין |
| ויהי, ויאמר, any biblical vav-consecutive | normal past tense |
| possessive suffixes in casual speech: נשמתך, ביתי, אחי (=my brother) | הנשמה שלך, הבית שלי, אח שלי |
| over-formal verbs: להתהלך, לשוב, להשיב, לחזות, להיוותר | ללכת, לחזור, לענות, לראות, להישאר |
| בני האדם (when a monster talks casually) | בני אדם, אנשים, "האדם" for the player |

Possessive suffixes are fine in fixed everyday phrases (בעצמי, לדעתי, שמי in a formal intro by a formal character, אבי
for Asgore talking like a king only if natural). In casual speech, use של.

## 2. Accuracy

- **Translate the meaning, never word by word.** Know the scene. Use your Undertale knowledge of who speaks, to whom, and why.
  - English idioms become Hebrew idioms: "hard-boiled" is a joke about eggs and toughness; "break a leg" = "בהצלחה";
    "no-brainer" = "ברור"; "pull my leg" = "עובד עליי".
  - A literal calque that makes no sense in Hebrew is a bug.
- **Gender must be right**, in verbs, adjectives and self-references:
  - female: Toriel, Undyne, Alphys, Muffet, Bratty, Catty, the Snowdin shopkeeper (bunny), the Nice Cream Guy's...
    check each NPC;
  - male: Sans, Papyrus, Asgore, Mettaton, Burgerpants, Gerson, Grillby, Monster Kid (use masculine for MK);
  - Napstablook and Frisk: gender-neutral where it's easy, otherwise masculine;
  - addressing the player: masculine singular, or neutral when it reads naturally.
- **Jokes and puns must work in Hebrew.** If the English pun can't survive, invent a Hebrew pun in the same spirit
  (bone puns for Sans, snow puns for Snowdrake, Toriel's snail puns, Temmie's misspellings). A pun that only works in English is a bug.
- **Keep the facts:** numbers, item names (glossary), place names, plot facts, who did what.
- **Choices and menu options** are short verbs or nouns (כן / לא, לאכול / להשאיר).

## 3. Character voices

Each character must be recognisable from one line, without the portrait.

- **Narrator / flavour text (`*`):** dry, witty, short. Modern Hebrew.
  - Check-text style: "* פרוגיט - ATK 4 DEF 5&* החיים די מבלבלים בשבילו."
  - Monster flavour lines are funny, not solemn.
- **Flowey:**
  - "Howdy!" = "שלום שלום!" (the same greeting as Asgore; that's a plot hint).
  - Early on he's a kids'-TV host, over-sweet: "חבר!", "ממש!", "הי הי הי".
  - Then mean and mocking with modern trash talk: "יא אידיוט", "באמת חשבת ש...?", "חחח", "איזה מטומטם".
  - "In this world, it's kill or BE killed." = "בעולם הזה, או שאתה הורג, או שהורגים אותך."
- **Toriel:**
  - Warm, caring mum. Polite and a bit proper, but modern: no archaic words.
  - "My child" = "ילדי" (her signature; keep it), sometimes "ילד יקר", "מתוק".
  - She loves bad puns and silly jokes and gets excited about pie, snails and books.
  - When firm, she's short and serious, not biblical.
- **Sans:**
  - The most relaxed, laid-back speaker in the game. Short sentences, spoken slang:
    "אהלן", "אחי", "חבוב", "סבבה", "נו", "חח", "טוב, לא משנה", "כאילו", "מה קורה".
  - "heya" = "אהלן". "kiddo/kid/pal/buddy" = "ילד", "אחי", "חבוב".
  - Constant bone/skeleton puns, recreated in Hebrew ("אין לי אומץ... אין לי גוף בשביל זה", "עצם העניין", "עד לשד העצמות").
  - In serious moments (Judgment Hall, the fight) he is calm and chilling but still casual. He never gets formal.
- **Papyrus:**
  - LOUD, theatrical, naive, sweet. He thinks he's an epic hero.
  - Speaks grandly but with words everyone knows: "מרהיב!", "אגדי!", "ללא ספק!", "בלתי נתפס!", "פאפירוס הגדול!".
  - Refers to himself in the third person a lot. Lots of !!!.
  - "NYEH HEH HEH!" = "נייה הה הה!". "WOWIE!!" = "וואו-וואו!!". "HUMAN!" = "בן אדם!" or "אנושי!" (pick one: "בן אנוש!" is too biblical; use "בן אדם!").
  - Gets flustered: "א-אה!", "אוי לא!". Cooks spaghetti with total pride.
- **Undyne:**
  - Loud, intense, competitive, sporty, a total action-anime fan. Short punchy shouting with lots of !!!.
  - "NGAHHH!!!" = "נגאההה!!!". "punk" = "יא פרחח" / "יא קטן". "Alright!" = "יאללה!". "seven" = "שבע".
  - Over the top: "אני אפרק אותך!", "אין מצב!". She cares deeply and is awkward about it.
  - On dates she's flustered and aggressive. Female verbs.
- **Alphys:**
  - Nervous, anxious, a total nerd: anime, manga, the internet, sci-fi. Stutters with hyphens ("א-אני", "ז-זה").
  - Rambles, apologises, corrects herself ("כ-כלומר...", "ז-זאת אומרת"), and uses geeky words.
  - Over text messages she writes like a fangirl ("אלוהים!!!", emojis written as words). Female verbs.
- **Mettaton:**
  - TV host, diva, show-off, theatrical and flirty. "OH YES." = "אה, כן."
  - "BEAUTIES AND GENTLEBEAUTIES" = "גבירותיי ויפהפיי".
  - Uses showbiz terms in Hebrew: "רייטינג", "פריים טיים", "קהל יקר", "מותק", "יקירי".
  - MTT brand everything. NEO/EX are dramatic. Male.
- **Asgore:**
  - Gentle, kind, sad, a little awkward fatherly king. Simple, warm, polite words; not grand or biblical.
  - "Howdy!" = "שלום שלום!". He loves gardening and tea.
  - In the final fight he's sad and short.
- **Asriel:**
  - As a child, a sweet kid: "וואו!", "איזה כיף", "תסתכל!".
  - As the god of hyperdeath, boastful, yet a crying kid underneath. Childish taunts ("אתה לא מבין, נכון?!"), not epic poetry.
- **Napstablook:** whispery, sad, self-deprecating, short. "אה...", "סליחה...", "זה בסדר...", "לא משנה...". Lots of "...".
- **Muffet:** sweet, mocking spider-boss. "אהוהוהו", "מותק", "יקירי", purring and businesslike about money.
- **Gerson:** a cheerful old grandpa. "וואה הה הה!", "ילד", "בזמני...". Old-man warmth, not an old book's Hebrew.
- **Temmie:** broken baby-talk, misspelled on purpose, very excited.
  - "hOI!!! i'm tEMMIE!!" = "הוי!!! אנ טמי!!".
  - Mix letters ("אנ", "תמי", "קולג'" = "קולג'!!!"), capitalised-energy feeling.
  - "tem flakes" = "פתיתי טמי".
- **Monster Kid:** excited kid. "יו!", "אחי!", "וואו, מגניב רצח!", "סתם...". Hero-worships Undyne. Male.
- **Bratty & Catty:** valley-girl / Tel Aviv teen talk. "כאילו,", "וואי", "אלוהים", "ממש ממש", "סטוּפּ", "יאאא".
- **Burgerpants:** burned-out, sarcastic young worker who hates his job. "אחי...", "תקשיב", "פשוט... תהרגו אותי", "כמובן", "בטח, מה שתגיד". Soft swearing ("לעזאזל", "חרא").
- **Shopkeepers / townsfolk:** each gets a natural, small personality. The Snowdin bunny is friendly and cheerful.
- **Doggo, Dogamy & Dogaressa, Lesser/Greater Dog:** dog-cop slang, simple. Dogamy/Dogaressa are a lovey-dovey couple ("מותק").
- **RG 01 / RG 02:** two bro guards. "אחי", "בנאדם", awkward bro-feelings.
- **Mad Dummy:** furious, petty, spits insults ("טיפשים!", "שקט!"). Napstablook's cousin.
- **Grillby:** silent.
- **Chara / genocide-route narration:** cold, short, flat. "* אבל אף אחד לא בא." No flowery words.
- **Gaster / wingdings:** keep as it is.

## 4. Process for each batch

1. Read `translation/glossary.md` (names, items, technical rules) and this guide.
2. The input is `translation/batches/bNN_rev.json`, a list of {id, en, he, max, where, voice_hint?} in game order.
   - `he` is the current Hebrew.
   - `voice_hint` comes from the text sound the game uses: Toriel, Sans, Papyrus, Undyne, Alphys, Mettaton, Asgore,
     Asriel, Flowey, Temmie. Strings without a hint are the narrator or other NPCs; use `where` and the scene.
3. For every string, decide whether the current Hebrew is fine, then improve it:
   - Make it accurate: right meaning, right gender, jokes that work.
   - Use everyday words.
   - Give it the speaker's voice.

   Expect to change most dialogue lines. Plain system/menu text that is already correct can stay.
4. Write `translation/he/bNN.json`: one JSON object with every id in the batch.
   - Keep the format: backslashes doubled in JSON, ASCII quotes, no niqqud.
   - For big batches, write parts and merge with Python; then delete the part files.
5. Run `PYTHONIOENCODING=utf-8 python scripts/check_batch.py translation/he/bNN.json` and fix every E-* error until BATCH PASS.
   - Control codes and terminators must match exactly; lines must fit `max`.
   - If a better line doesn't fit, shorten it; don't fall back to stiff wording.
6. Append a short section to `translation/notes/bNN_notes.md` headed `## Voice pass`: notable choices and new puns.
