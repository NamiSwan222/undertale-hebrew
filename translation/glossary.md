# Undertale Hebrew: glossary and style guide

This guide is binding for every translation batch. If you need a new recurring term,
add it under "Added during translation" at the bottom with the batch number.

## General decisions

- **Addressing the player (Frisk / "you"):** use masculine singular (אתה, הלכת, מוכן), the usual
  convention in Hebrew games. Where it reads naturally, use wording that avoids gender
  (e.g. "הגיע הזמן לזוז" instead of "אתה צריך לזוז"). Never use slashes like "מוכן/ה".
- **Frisk** is referred to by others with gender-neutral wording where possible. If you can't avoid
  it, use masculine.
- **Chara**: also gender-neutral where possible, otherwise masculine.
- **Register:** natural, modern, spoken Hebrew. No biblical or bureaucratic Hebrew unless
  the character speaks that way (Asgore and Toriel are a bit more formal; Gerson is old-fashioned).
- **Narration** starts with "* " like the English. Keep the "* " exactly where the English has it.
- **Continuation lines** in the same paragraph start with two spaces ("  "), like the English.
- **Puns and jokes:** don't translate literally if the joke dies. Write an equivalent Hebrew pun or
  joke that fits the scene. Sans and Toriel puns, Papyrus's puzzles and the Temmie misspellings
  should stay funny in Hebrew.
- **Niqqud:** don't use it.
- **Quotation marks:** use the ASCII " and '. Use ASCII "-" for the maqaf.
- **Numbers, LV, HP, EXP, G (gold), AT, DF** and button names (Z, X, C, ENTER, SHIFT, CTRL, ESC)
  stay in Latin characters and digits. The engine handles the bidirectional order.
- **Keep untranslatable strings** as they are (e.g. "%%%", " ", "--", lone punctuation, "...").

## Technical rules (the checker enforces these)

1. Copy every control code exactly and in the same order: `\E0`..`\E9`, `\F1`, `\M1`, `\TS`, `\T-`,
   `\S-`, `\z4`, `\*Z`, colours `\R \G \W \Y \X \B \O \L \P \p`, `\C`, `^1`..`^9`, substitutions
   `\[C]` `\[G]` `\[I]` `\[1]`..`\[7]`, and the terminators `/`, `%`, `/%`, `/%%`, `%%`, `%%%`.
   Colour codes wrap the coloured words. Move them together with the word in the Hebrew sentence,
   but keep the same order and count of codes.
2. `&` is a line break inside a box, and `#` is a line break in menu text. You may move them or add
   or remove `&` to fit Hebrew line lengths. A message (the text between terminators) can have at
   most 3 lines (or as many as the English has, if more).
3. **Line width:** each Hebrew line must be no wider than the `max` given for that string (in cells,
   where 1 cell = one fixed-width English character). Hebrew letters are narrower: most count as 1,
   ו י ן count as about 0.6, and ש as 1.25. Run `python scripts/check_batch.py <your output file>`; it computes this exactly.
4. Don't add or remove messages. The number and order of `/` and `%` terminators must match.
5. Strings that end in spaces or are padded with spaces to line up (menus, choice lines with `\C`)
   keep the same total layout. For **choice lines** (containing `\C`), put each Hebrew option at the
   same column where the English option starts, padded with spaces like the English. The first
   option stays on the left.
6. Empty or symbol-only strings (" ", "%%%", "--") are copied as-is.
